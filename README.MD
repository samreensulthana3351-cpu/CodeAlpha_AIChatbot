# CodeAlpha AI Chatbot

A beginner-friendly rule-based chatbot developed using Java
as part of the CodeAlpha Java Programming Internship.

## Features
- Interactive text-based conversation
- Responds to greetings and common questions
- Keyword matching and predefined responses
- Handles unknown messages
- Exit command to end the conversation

## Technologies Used
- Java
- Scanner
- Conditional statements
- Loops and methods
- String handling

## How to Run

Compile:
javac AIChatbot.java

Run:
java AIChatbot

## Project Type
Console-based rule-driven chatbot.
